# WeatherNow (웨더나우) 🌤️

별도의 API 키 발급 없이 무료로 즉시 사용할 수 있는 실시간 날씨 웹 애플리케이션입니다.

---

## ✨ 주요 기능

1. **실시간 날씨 정보 조회**
   - 현재 기온, 체감 온도, 당일 최저/최고 기온
   - 날씨 상태 설명 (맑음, 흐림, 비, 눈, 뇌우 등) 및 동적 아이콘
   - 습도(%), 풍속(m/s), 강수 확률(%), 자외선(UV) 지수, 기압(hPa), 일출/일몰 시각

2. **24시간 시간별 예보 & 7일간 주간 예보**
   - 현재 시간부터 향후 24시간 동안의 기온과 강수 확률을 가로 스크롤로 확인
   - 주간 날씨 상태와 최고/최저 기온 범위 게이지 시각화

3. **도시 검색 및 빠른 바로가기**
   - 국내 및 해외 주요 도시(서울, 부산, 제주, 도쿄, 뉴욕, 파리 등) 원클릭 바로가기 칩 제공
   - 한글/영문 도시명 검색 및 자동완성 추천 지원

4. **현재 위치 기반 날씨 (GPS)**
   - `내 위치` 버튼을 누르면 브라우저의 Geolocation API를 통해 현재 계신 곳의 날씨를 자동 조회

5. **섭씨(°C) / 화씨(°F) 토글**
   - 버튼 클릭 한 번으로 모든 온도를 실시간 변환하며, 브라우저 로컬 스토리지에 설정값 저장

6. **감성적인 글래스모피즘(Glassmorphism) & 날씨 반응형 배경**
   - 맑은 날, 흐린 날, 비, 눈, 밤하늘 등 현재 날씨와 주/야간 상태에 따라 배경 테마 그라데이션 자동 전환
   - 모바일과 데스크톱 모두에 최적화된 반응형 웹 디자인

## 🚀 사용된 공개 API (무료 & API Key 불필요)

| API 명칭 | 용도 | 특징 |
| :--- | :--- | :--- |
| **[Open-Meteo](https://open-meteo.com)** | 실시간 기상 관측 및 예보 | 완전 무료, API Key 발급 불필요, WMO 표준 코드 지원 |
| **[OpenStreetMap Nominatim](https://nominatim.openstreetmap.org)** | 도시명 지오코딩 | 한국어 및 전 세계 지명 검색 지원, 무료 공개 API |
| **[BigDataCloud Client Reverse Geocode](https://api.bigdatacloud.net)** | GPS 좌표 지명 변환 | 무료, API Key 불필요, 한국어 행정구역명 반환 |

## 💻 실행 방법

### 방법 1: 브라우저에서 바로 열기
1. 폴더 안의 `index.html` 파일을 더블 클릭합니다.
2. 기본 웹 브라우저(Chrome, Edge, Safari 등)에서 즉시 실행됩니다.

### 방법 2: 로컬 웹 서버로 열기 (VS Code 등)
- VS Code의 **Live Server** 확장을 사용하거나, 터미널에서 다음 명령어로 로컬 서버를 실행할 수 있습니다:
```bash
# Python 내장 서버 실행 예시
python -m http.server 8080
```
그 후 브라우저에서 `http://localhost:8080`에 접속합니다.
